# sample_records.jsonl

Purpose: a reference example of the `records.jsonl` the pipeline produces, so
the record format can be read without a full run in hand.

- 48 lines = one matched triple (3 topologies x 4 agents x 4 rounds).
- Format is real and current (generated by running the pipeline), but the
  content is from the MOCK client, so every `rationale` is the placeholder
  "Mock default rationale." — good for reading the field layout, NOT for
  anything that depends on response content. Real rationales come from the
  Azure pilot run.
- Not a fixture for tests; purely documentation. Regenerate with:
  `uv run python scripts/run_pilot.py --client mock --scenario travel_001 \
     --variants factual --n-seeds 1 --skip-baselines --skip-independent`
